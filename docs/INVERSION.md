# CitaClara — Documento para inversión

**Estado:** MVP técnico listo (app + backend + Stripe)
**Repo:** https://github.com/jonnathan1990/cita-clara

## Problema
Apps de citas maximizan tiempo en app y fricción de salida. Desconfianza y abandono.

## Solución
Monetización ética verificable: precio solo país+plan, cancel ≤2 pantallas, IA visible/borrable, seguridad gratis, pausa por éxito.

## Producto
Expo + Supabase + Stripe. Mercado inicial México; expansión US/ES.

## Modelo
Suscripción CitaClara+ monthly/quarterly. Precios locales.

## Uso de fondos (ejemplo)
40% producto | 30% adquisición | 15% operaciones | 15% legal/reserva

## Ask
[Monto] por [equity %] — lanzamiento 2–3 ciudades, 90 días de métricas.

*Informativo; no constituye oferta de valores.*
